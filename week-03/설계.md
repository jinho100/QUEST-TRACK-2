# 숲의 생존자 · 설계 메모

파일: `week-03/survival.html` (three.js r128, 파일 하나)

## 게임 규칙 (정한 것)
- 3D 생존 게임. 숲에서 살아남기. 마인크래프트와 디자인이 다르고, 현실적인 풀과 흙 느낌
- 무한 맵, 매끄러운 언덕 땅 (블록 격자 아님)
- 블록(나무·바위·광맥)은 도구가 있어야 부술 수 있음
- 땅은 삽으로만 조금 팔 수 있음
- 중력: 플레이어, 벤 나무(쓰러짐). 동굴은 지반이 단단해서 받침 기둥을 세우면 무너지지 않음
- 조작: WASD 이동, Space 점프, Shift 웅크리기, Ctrl 달리기, 마우스 휠 핫바, E 인벤토리, Q 버리기

## 단계
- [x] 1단계: 무한 숲 지형, 이동, 낮과 밤
- [x] 2단계: 바닥 재료 줍기(F키, 나무 밑 55% 확률로 막대기 1~2개, 조약돌은 여기저기·바위 근처에 더 많음), 인벤토리 30칸, 핫바(휠·1~0), E·Q, 무게 1kg마다 이동 속도 0.4% 감소(최대 30%), 하트 10칸·배고픔·목마름·체온 표시(수치가 변하는 건 4단계)
- [x] 3단계 앞부분 (2026-11-05)
  - 줍기 키를 좌클릭으로 바꿈 (누르고 있으면 계속 베기)
  - 인벤토리 안에 4×4 제작대, 레시피는 모양대로 놓기(위치 자유, 좌우 뒤집기 가능)
    - 돌도끼: 조약돌 3 + 막대기 2 (도끼 모양), 내구도 80
    - 통나무 1 → 막대기 4
  - 도끼로 나무 베기: 참나무 6번, 자작나무 5번, 소나무 8번. 나를 등지고 쓰러지고, 그루터기가 남음. 통나무 2~4개, 막대기, 남은 사과가 떨어짐
  - 활엽수의 30%는 사과나무 (도끼 없이 좌클릭하면 흔들어서 사과가 떨어짐, 밑에도 떨어져 있음)
  - 블루베리는 나무에서 따기 어려워서 낮은 덤불에 열리게 함
  - 그늘(숲이 빽빽한 곳의 나무 밑, 죽은 통나무 옆)에 갈색 버섯·빨간 버섯
  - 죽은 통나무: 뛰어넘을 수 있고, 도끼로 3번 자르면 통나무가 나옴
- [x] 3단계 뒷부분 (2026-11-05)
  - 암석 지대: 블록으로 된 바위 언덕(약 100m마다 40% 확률). 안쪽에 광맥 덩어리
    - 구리·주석·석탄: 돌 곡괭이 / 철: 청동 곡괭이 이상 (2칸 이상 깊이) / 알루미늄: 철 곡괭이 (3칸 이상 깊이)
  - 무너짐: 바위를 캤을 때 위에 바위가 있고 지지대가 2칸 안(아래 3칸까지)에 없으면 25~73% 확률로 위쪽 바위(최대 4개)가 떨어짐. 맞으면 하트 2.5칸
  - 블록 놓기(우클릭): 돌, 흙, 판자 블록, 돌 벽돌, 지지대, 화로, 용광로, 횃불
  - 삽: 땅을 조금씩 팜(최대 2m), 흙이 나옴
  - 물가 풀 → 풀 줄기 → 끈
  - 화로: 재료 2칸 + 연료 + 결과. 구리+주석 → 청동. 통나무 → 숯. 알루미늄은 용광로에서만
  - 도구 단계: 돌 → 청동 → 철 (도끼·곡괭이·삽·창, 검은 청동부터). 금속 도구는 틀 + 주괴 + 막대기 (틀은 남음)
  - 횃불: 굴 안을 밝힘 (가까운 불빛 6개까지)
  - 관리자: `/` 채팅에 관리자12345 → Space 두 번 날기, 인벤토리에 모든 아이템, /낮 /밤 /끄기
  - 높은 곳에서 떨어지면 다침

- [ ] 5단계: 밤에 좀비 습격
